# TP Todo React MongoDB


## Pasos para la ejecución

1. Ingresar a cada carpeta de proyecto:
   ```bash
   cd tp_adm_tareas         # Para el frontend
   cd tp_adm_tareas_backend # Para el backend
   ```

2. Instalar las dependencias en cada proyecto:
   ```bash
   npm install
   ```

3. Ejecutá el servidor de desarrollo:
   ```bash
   npm run dev
   ```

## Configuración

Es necesario renombrar el archivo `.env.example` a `.env` en el proyecto backend para su correcto funcionamiento.
